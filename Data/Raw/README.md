# Financial knowledge-base sources

Place trusted financial `.pdf`, `.txt`, or `.md` files in this folder. The retrieval agent ignores this README.

For the final system, use approximately 10–20 documents from authoritative sources such as the Central Bank, Securities and Exchange Commission, stock exchange, and regulated-bank education pages. Record the original URL, title, publisher, publication date, and download date for every document in the group report.

The included `demo_finance_knowledge.txt` is only for development and the mid-evaluation demo. Replace it with cited sources before final submission.
